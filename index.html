Reportes en el acumulado

Si dos reportes cubren el mismo día, se usa el generado más recientemente; el otro queda reemplazado para esos días.

Cómo subir un reporte nuevo

  1. Descarga el Excel del sistema (mismo formato: hojas Resumen, Por ruta y Detalle).
  2. Pulsa ⬆ Subir reporte (requiere cuenta de GitHub con permiso de escritura en el repositorio).
  3. Arrastra el archivo y pulsa Commit changes.
  4. En 2–4 minutos el panel se recalcula solo. Recarga la página.

Puedes volver a subir un mes que ya existe (por ejemplo, octubre completo): reemplaza los días que se solapan sin duplicar.
